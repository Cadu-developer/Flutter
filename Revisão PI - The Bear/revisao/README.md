# Revisão Prática e Teórica — The Bear

## Questões Teóricas

### 1. O que é MVVM?
Padrão que separa Model, View e ViewModel.

### 2. Qual a função do Model?
Representar os dados do sistema.

### 3. Qual a função da View?
Exibir a interface e receber ações do usuário.

### 4. Qual a função do ViewModel?
Controlar estados e regras da interface.

### 5. Por que usar Service?
Para separar o acesso ao banco da lógica da aplicação.

### 6. Por que a View não deve acessar o SQLite?
Para manter a separação de responsabilidades.

### 7. Para que serve o Provider?
Gerenciar e disponibilizar os ViewModels.

### 8. Para que serve o `notifyListeners()`?
Avisar a interface que o estado mudou.

### 9. O que é SQLite?
Um banco de dados local e persistente.

### 10. Qual a diferença entre RAM e SQLite?
RAM é temporária; SQLite mantém os dados salvos.

### 11. O que é CRUD?
Criar, Ler, Atualizar e Excluir dados.

### 12. Quais comandos SQL representam o CRUD?
`INSERT`, `SELECT`, `UPDATE` e `DELETE`.

### 13. Como calcular o total do pedido?
`quantidade × valor unitário`.

### 14. Quando o pedido é considerado grande?
Quando a quantidade é **5 ou mais**.

### 15. Qual o status inicial do pedido?
**Pendente**.

### 16. O que acontece ao finalizar um pedido?
O status muda para **Finalizado** no banco e na tela.

### 17. O que acontece ao excluir um pedido?
O pedido é removido do banco e da lista.

### 18. Qual o fluxo correto do MVVM?
**View → ViewModel → Service → SQLite**.
